# Бумага — Paper House

First-person прототип про дом, бумагу и ручную работу в духе *Find The Needle*.
Сделан на Unity 6000.6.7f1 (URP).

## Что внутри

- Дом с интерьером, дверью, прозрачными окнами и ночным освещением.
- Бесконечная стопка бумаги, коврик (максимум 1 лист), складка по силе.
- Большой зелёный контейнер за домом — сдача бумаги за деньги.
- Стул и ноутбук: древо прокачки силы, скорости и эффективности.
- Древо открывается только со стула.
- `Q` — запустить сложенный лист к луне.
- 10 декоративных домиков вокруг, ночное небо, луна, звёзды.
- Настройки: музыка, эффекты, чувствительность мыши.
- Звуки: шаги, дверь, бумага, лампа, монета, ветер, фоновая музыка.

Подробности: [PAPER_HOUSE.md](PAPER_HOUSE.md) и [DSH_ASSISTANT.md](DSH_ASSISTANT.md).

## Запуск

1. Откройте проект в Unity **6000.6.7f1**.
2. Откройте `Assets/Scenes/SampleScene.unity`.
3. Нажмите **Play**.
4. Кликните по вкладке **Game** (появится стартовая карточка), затем играйте.

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` | ходьба |
| мышь | обзор |
| `Shift` | бег |
| `Space` | прыжок |
| `E` | взаимодействие |
| `Q` | запустить бумагу к луне |
| `Esc` | настройки / пауза |
| `F1` | записка DSH |

## Основные файлы

- `Assets/House/Editor/HouseBuilder.cs` — генератор дома, интерьера, городка и ночи.
- `Assets/House/Runtime/` — FPS-контроллер, взаимодействия, HUD, настройки, прокачка.
- `Assets/House/Audio/` — пользовательские MP3 и сгенерированные WAV.
- `Assets/Scenes/SampleScene.unity` — игровая сцена.
- `Tools/DSHBridge/` — локальный мост к OpenAI-совместимому API для DSH-ассистента.

## Примечания

- `Library/`, `Temp/`, `Logs/`, `UserSettings/` не входят в репозиторий.
- Настройки звука и мыши сохраняются в `PlayerPrefs`; деньги и уровни — в рамках Play-сессии.
- Городок декоративный: взаимодействий с домиками нет.
